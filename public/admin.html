Ingia kwa password yako binafsi ya dashboard. Hii si password ya wateja na inathibitishwa na server.

Kama bado hujaweka password: Cloudflare → Workers & Pages → 343shop → Settings → Variables and Secrets → Add Secret → OWNER_PASSWORD. Tumia password yenye angalau herufi 8; herufi nyingi zaidi ni salama zaidi. MCP_WRITE_TOKEN ibaki tofauti kwa AI/MCP plugin. Usitume password au token kwenye chat.
