Weka Gemini API

Key haitakiwi kuandikwa hapa. Iweke kama Secret kwenye Cloudflare.

  1. Fungua Google AI Studio na utengeneze Gemini API key.
  2. Cloudflare → Workers & Pages → 343shop → Settings → Variables and Secrets.
  3. Ongeza Secret yenye jina GEMINI_API_KEY.
  4. Save, redeploy Worker, kisha refresh hii dashboard.
